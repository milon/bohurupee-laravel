# Security Policy

`milon/bohurupee-laravel` is a **dev-only** adapter. It refuses to boot when
`APP_ENV=production`. Pointing a real app at Bohurupee in production is not
supported.

File bugs on
[GitHub Issues](https://github.com/milon/bohurupee-laravel/issues). For the Go
server, use [milon/bohurupee](https://github.com/milon/bohurupee/issues).
