# Security Policy

`milon/bohurupee-laravel` is a **dev-only** adapter. It refuses to boot when
`APP_ENV=production`. Pointing a real app at Bohurupee in production is not
supported.

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/milon/bohurupee-laravel/security/advisories/new)
(or the [core Bohurupee advisory form](https://github.com/milon/bohurupee/security/advisories/new)
if the issue is in the Go server).
